# Anemia Prediction System

---

Este proyecto tiene como objetivo desarrollar un modelo de Machine Learning capaz de predecir la presencia de anemia 
mediante variables hematológicas como hemoglobina, MCV y MCH.

La anemia es una enfermedad caracterizada por la disminución de glóbulos rojos o hemoglobina, 
afectando el transporte de oxígeno en el organismo. 
Es un problema de salud pública global que afecta principalmente a niños y mujeres embarazadas.

A partir de datos clínicos y análisis hematológicos, se entrenarán modelos de clasificación binaria para 
identificar pacientes con riesgo de padecer anemia y evaluar el rendimiento predictivo de distintas 
técnicas de Machine Learning.
